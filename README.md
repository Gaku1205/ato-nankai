# ato-nankai

専門学校・大学生向けに、授業ごとの欠席を1タップで数え、単位を落とさずにあと何回休めるかを大きな数字で出すスマホ向けWebアプリ

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（あと何回休める？ 専門学校・大学生向け。授業ごとに欠席を1タップで数えて、単位を落とさずにあと何回休めるかを出すスマホ向けWebアプリ。ログイン無し・データは端末だけ）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
